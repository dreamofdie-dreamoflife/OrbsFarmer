## Что это

**TrustQuests** — JavaScript-скрипт, который запускается прямо в консоли Discord и автоматически выполняет квесты (Quests) на вашем аккаунте. Скрипт работает как в обычном клиенте Discord, так и при наличии [Vencord](https://vencord.dev/).

Поддерживаются все типы квестов:

| Тип квеста | Описание |
|---|---|
| `GAME` | Играть в игру (подделывает запущенный процесс) |
| `STREAM` | Стримить игру |
| `WATCH_VIDEO` | Смотреть видео |
| `ACHIEVEMENT` | Достижение внутри активности |
| `ACTIVITY` | Активность в голосовом канале |

## Возможности

- 🚀 **Параллельный запуск** — все доступные квесты стартуют одновременно
- 🔄 **Авто-запись на квест** — `autoEnroll` включён по умолчанию
- 🏆 **Авто-получение награды** — опционально (`autoClaim`, по умолчанию выключено)
- 🛡️ **Обход CSP для Achievement-квестов** — через Discord Says bypass или Trust Relay
- 🔁 **Retry-логика** — до 3 повторных попыток при сетевых ошибках
- ⏱️ **Таймаут** — квест автоматически прерывается через 25 минут если нет прогресса
- 🔔 **Desktop-уведомления** — по завершении каждого квеста (опционально)
- 🔊 **Звуковые сигналы** — по завершении (опционально)
- 🖱️ **Перетаскиваемый UI** — HUD поверх Discord с логами и кнопками
- ⌨️ **Горячая клавиша** — `Shift+.` (символ `>`) скрывает/показывает UI
- 🔒 **Защита от дублей** — `window.trustLock` предотвращает двойной запуск

## Быстрый старт

### 1. Открыть DevTools в Discord

| Платформа | Комбинация |
|---|---|
| Windows / Linux | `Ctrl + Shift + I` |
| macOS | `Cmd + Option + I` |

Если DevTools заблокированы — сначала включите их через [Vencord](https://vencord.dev/) или запустите Discord с флагом `--remote-debugging-port=9222`.

### 2. Вставить скрипт

Перейдите во вкладку **Console**, вставьте содержимое файла `TrustQuests_console.js` и нажмите `Enter`.

```js
// Быстрый способ: скопировать файл и вставить целиком
// После запуска появится UI в правом верхнем углу экрана
```

### 3. Готово

Скрипт сам найдёт все незавершённые квесты и начнёт их выполнять. Прогресс виден в HUD-панели.

## Настройки

Настройки задаются в объекте `e` в начале функции `NO()`. Отредактируйте перед запуском:

```js
let e = {
  NAME: "Trust",
  VERSION: "v1.0",
  HIDE_ACTIVITY: false,       // Скрыть "Display current activity" на время квестов
  PLAY_SESSION_TAIL_MIN: 2,   // Держать игру запущенной ещё N минут после завершения квеста
  MAX_LOG_ITEMS: 60,          // Максимум строк в логе UI
};
```

Объект состояния `o` (можно менять на лету через консоль после запуска):

```js
// window.RUNTIME — ссылка на объект o после запуска
window.RUNTIME.autoClaim = true;   // Автоматически получать награды
window.RUNTIME.playSound = true;   // Звук при завершении
window.RUNTIME.randomDelay = true; // Случайная задержка между циклами (1-30 мин)
```

## Как это работает

```
Discord DevTools Console
        │
        ▼
   TrustQuests.js
        │
        ├── Ищет модули через Vencord.Webpack или webpackChunkdiscord_app
        │
        ├── Получает список квестов из QuestStore
        │
        ├── Для каждого незавершённого квеста:
        │     ├── GAME / STREAM  → подделывает запущенный процесс в RunningGameStore
        │     ├── WATCH_VIDEO    → отправляет прогресс просмотра через /video-progress
        │     ├── ACHIEVEMENT    → heartbeat-спуфинг или Discord Says bypass
        │     └── ACTIVITY       → heartbeat из голосового канала
        │
        └── Показывает прогресс в HUD-панели
```

### GAME / STREAM квесты

Скрипт инжектирует фейковый процесс в `RunningGameStore` Discord. Discord думает, что игра запущена, и засчитывает время. После завершения квеста процесс удаляется автоматически.

### WATCH_VIDEO квесты

Скрипт имитирует просмотр видео, отправляя POST-запросы на `/quests/{id}/video-progress` с нарастающим таймстемпом. Интервал между запросами: 7–9.5 секунд (случайный).

### ACHIEVEMENT квесты

Два пути:
1. **Heartbeat-спуфинг** — через `/quests/{id}/heartbeat` из голосового канала
2. **Discord Says bypass** — OAuth-авторизация через discordsays.com (требует подтверждения пользователя)

## Trust Relay

Для Achievement-квестов на Desktop-клиенте можно запустить локальный прокси **Trust Relay** на `http://127.0.0.1:43210`. Он обходит CSP Discord, позволяя скрипту достучаться до `discordsays.com`.

Без релея на Desktop скрипт всё равно попробует нативный путь через `DiscordNative.http.makeRequest`.

## Часто задаваемые вопросы

**Q: Скрипт не находит квесты**  
A: Перезагрузите Discord (`Ctrl+R`), дождитесь полной загрузки и запустите снова.

**Q: Квест завис со статусом RUNNING**  
A: Истечёт по таймауту через 25 минут и будет помечен как FAILED.

**Q: Achievement-квест пропускается**  
A: Либо квест возрастной/удалён, либо Discord не принимает heartbeat на этом аккаунте. Скрипт не может обойти это ограничение.

**Q: Можно ли запустить на Web-версии Discord?**  
A: Частично. GAME/STREAM квесты требуют Desktop-клиента. VIDEO и некоторые ACHIEVEMENT работают в браузере.

**Q: Скрипт запустился дважды**  
A: Защита `window.trustLock` предотвращает это — повторный запуск просто покажет существующий UI.

## Ограничения и риски

> ⚠️ **Используйте на свой страх и риск.**

- Автоматизация квестов нарушает [Terms of Service Discord](https://discord.com/terms)
- Discord может заблокировать аккаунт или отозвать квестовые награды
- Achievement-квесты через OAuth временно авторизуют приложение на вашем аккаунте — скрипт отзывает доступ сразу после завершения, но при сбое токен может остаться (проверьте в **Настройки → Авторизованные приложения**)
- Скрипт не хранит и не передаёт токен Discord — все запросы идут через внутренний API клиента
